隱私權政策

最後更新：2026年5月

一、資料控制者

AI 旅譯（以下稱「本服務」）由個人開發者營運。如對本政策、資料刪除、帳號刪除或使用條款有任何疑問，請透過電子郵件聯絡：jack7896321@gmail.com

二、我們蒐集的資料

使用本服務時，我們可能蒐集以下資料：

1. 帳號資訊

當您以 Google 或 Apple 帳號登入時，我們會取得您的名稱、Email 地址及頭像網址，用於識別身分及提供雲端同步服務。

2. 翻譯輸入文字、圖片與語音

您輸入的文字、語音轉成的文字，或上傳的圖片，會傳送至 OpenAI API 進行翻譯處理。翻譯結果可儲存於您的帳號或裝置中，以供歷史紀錄查閱。

3. 使用記錄

我們記錄功能的每日使用次數（例如翻譯、語音輸入、拍照翻譯等），用於實施免費版使用限制、訂閱功能限制及防止異常使用。

4. 旅遊記帳、記事、自訂常用句與收藏資料

您在記帳、記事、自訂常用句及收藏功能輸入或保存的內容，僅用於提供服務，不會用於廣告或出售給第三方。

三、資料傳送對象

  • OpenAI（翻譯處理）
    翻譯、拍照翻譯及語音輸入相關功能會將必要內容傳送至 OpenAI API 進行處理。OpenAI 的隱私政策請參閱 openai.com/privacy。
  • Google Firebase（登入與雲端儲存）
    帳號資料、翻譯紀錄、記帳、記事、自訂常用句及收藏資料可能儲存於 Google Firebase（Firestore），用於登入、同步與資料備份。
  • Cloudflare（API 代理）
    翻譯請求會透過 Cloudflare Workers 代理轉發，用於保護 API 金鑰及實施使用量限制。
  • RevenueCat（訂閱管理）
    訂閱狀態由 RevenueCat 協助處理。本服務不直接儲存信用卡號或付款資料；付款紀錄由 Google Play、Apple App Store 或相關付款平台依其政策處理。

四、資料保留期限

  • 帳號資料：帳號存續期間持續保留。
  • 翻譯歷史、記帳、記事、自訂常用句與收藏資料：帳號存續期間持續保留，或直到您於 App 內刪除該資料。
  • 訂閱狀態資料：為提供旅遊模式與訂閱恢復功能，會於必要期間內保留；付款紀錄依 Google Play、Apple App Store 或 RevenueCat 的政策保留。

五、帳號刪除與資料刪除

1. 刪除帳號

如需刪除帳號，請開啟 AI 旅譯 App，前往「設定」頁面，選擇「刪除帳號」。刪除帳號後，與該帳號相關的個人資料及雲端同步資料將一併刪除，包括帳號資料、翻譯歷史、記事、旅遊記帳資料、收藏與自訂常用句等。

2. 刪除部分資料

使用者不必刪除帳號，也可以在 App 內刪除部分資料，例如翻譯歷史、記事、旅遊記帳資料、自訂常用句與收藏內容。

3. 第三方資料保留

帳號刪除後，我們會刪除可由本服務控制的帳號與使用資料。部分由第三方服務處理的資料，例如 Google Play、Apple App Store 或 RevenueCat 的付款與訂閱紀錄，將依各平台或服務提供者的政策保留。

六、資料安全

本服務透過 HTTPS/TLS 傳輸資料，並使用 Firebase、Cloudflare、RevenueCat 等第三方服務提供的安全機制保護資料。請您妥善保管自己的 Google 或 Apple 帳號。

七、兒童隱私

本服務不以 13 歲以下兒童為主要對象，亦不會故意蒐集 13 歲以下兒童的個人資料。

八、聯絡方式

如對本隱私權政策、資料刪除、帳號刪除或使用條款有任何疑問，請透過電子郵件聯絡：jack7896321@gmail.com

九、適用法律

本隱私權政策依中華民國法律解釋及執行，因本政策所生之爭議，以中華民國法院為管轄法院。
