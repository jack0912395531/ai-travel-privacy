隱私權政策

最後更新：2025年

一、資料控制者

AI 旅譯（以下稱「本服務」）由個人開發者營運。如對本政策有任何疑問，請來信：jack0912395531@gmail.com

二、我們蒐集的資料

使用本服務時，我們可能蒐集以下資料：

1. 帳號資訊

當您以 Google 或 Apple 帳號登入時，我們會取得您的名稱、Email 地址及頭像網址，用於識別身份及提供雲端同步服務。

2. 翻譯輸入文字

您輸入的文字或上傳的圖片，將傳送至 OpenAI API 進行翻譯處理。本服務不會永久儲存翻譯的輸入原文；翻譯結果會儲存於您的帳號以供歷史紀錄查閱。

3. 使用記錄

我們記錄功能的每日使用次數（翻譯、語音輸入等），用於實施免費版使用限制，不會用於其他目的。

4. 旅遊記帳與記事資料

您在記帳及記事功能輸入的內容，僅用於提供服務，不會用於廣告或分析。

三、資料傳送對象

  • OpenAI（翻譯處理）
    翻譯功能會將您的輸入文字傳送至 OpenAI API 進行處理。OpenAI 的隱私政策請參閱 openai.com/privacy。
  • Google Firebase（雲端儲存）
    帳號資料、翻譯紀錄、記帳及記事資料儲存於 Google Firebase（Firestore），伺服器位於美國。Firebase 的隱私政策請參閱 firebase.google.com。
  • Cloudflare（API 代理）
    翻譯請求透過 Cloudflare Workers 代理轉發，Cloudflare 不會儲存請求內容。
  • RevenueCat（訂閱管理）
    訂閱購買資訊由 RevenueCat 處理，本服務不直接儲存付款資料。

四、資料保留期限

  • 帳號資料：帳號存續期間持續保留。
  • 翻譯歷史、記帳、記事：帳號存續期間持續保留；帳號刪除後立即刪除。
  • 旅遊模式訂閱資料：訂閱到期後 60 天內保留，期滿後自動刪除。

五、您的權利

您可隨時於設定頁面刪除帳號，帳號刪除後，所有雲端資料將於 24 小時內永久刪除。

六、兒童隱私

本服務不針對 13 歲以下兒童，亦不蒐集兒童個人資料。

七、聯絡方式

如有任何隱私相關疑問，請來信：jack0912395531@gmail.com
